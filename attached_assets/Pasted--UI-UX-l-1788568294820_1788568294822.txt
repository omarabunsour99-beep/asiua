أريد منك إعادة تصميم وتطوير **الموقع الحالي الموجود في هذا المشروع** بالكامل من ناحية الـUI/UX والـlayout والـresponsive behavior، بحيث يصبح قريبًا جدًا من **الهيكل وتجربة الاستخدام التي سأصفها أدناه**.

مهم جدًا:

* لا تنسخ كود الموقع المرجعي.
* لا تنسخ HTML/CSS/JS منه حرفيًا.
* لا تستخدم شعاره أو اسمه أو صوره أو روابطه أو أي Assets خاصة به.
* لا تستخدم دوميناته أو URLs الخاصة به.
* لا تغيّر اسم موقعي أو الـbranding الخاص بي.
* استخدم الـlogo والاسم والمحتوى الموجودين حاليًا في مشروعي.
* إذا كان هناك بيانات أو Components موجودة أصلًا في المشروع، حافظ عليها ولا تحذفها بدون سبب.
* المطلوب هو **إعادة بناء التصميم والـUX من الصفر** اعتمادًا على الـstructure والسلوك الموضحين هنا.
* لا تجعل الموقع نسخة حرفية؛ اجعله تصميمًا أصليًا لموقعي مع نفس الفكرة العامة، توزيع العناصر، الإحساس البصري، وسلوك المكونات.

# 1. قبل تعديل أي شيء

أولًا افحص المشروع الحالي بالكامل.

حدد:

* Framework المستخدم.
* Entry points.
* Routing.
* Components.
* Pages.
* Database/data models إن وجدت.
* طريقة جلب المسلسلات والأفلام.
* طريقة عرض الصور.
* نظام الـauthentication إن وجد.
* الـCSS/Tailwind/styling system المستخدم.
* أي API موجود.
* أي admin/dashboard موجود.

لا تعيد بناء المشروع من الصفر إذا لم يكن ذلك ضروريًا.

**حافظ على الـbackend والـdata الموجودة حاليًا قدر الإمكان.**

قم بتعديل الـfrontend/UI والـcomponents المطلوبة بدل حذف الوظائف الحالية.

# 2. اللغة والاتجاه

الموقع عربي بشكل أساسي.

يجب أن يكون:

```text
direction: rtl
lang: ar
```

ويجب أن يكون الـRTL حقيقيًا في:

* Header
* Navigation
* Dropdowns
* Search
* Cards
* Carousels
* Buttons
* Pagination
* Mobile menu
* Footer
* جميع الصفحات.

استخدم خط عربي حديث وواضح ومناسب لموقع مسلسلات.

# 3. التصميم العام

أريد موقعًا يبدو كموقع احترافي متخصص في:

* المسلسلات الكورية
* المسلسلات الصينية
* المسلسلات التايوانية
* المسلسلات اليابانية
* المسلسلات التايلاندية
* المسلسلات الفلبينية
* الأفلام الآسيوية
* البرامج الترفيهية

التصميم يجب أن يكون:

* نظيف.
* مرتب.
* حديث.
* سريع.
* Responsive.
* مناسب للـdesktop والـtablet والـmobile.
* التركيز الأساسي على Posters والمحتوى المرئي.

لا تستخدم Anime كتصنيف رئيسي، ولا تضف محتوى Anime إلا إذا كان موجودًا أصلًا في بيانات موقعي.

# 4. HEADER

أعد بناء الـHeader ليكون من أهم عناصر الموقع.

الـHeader يجب أن يحتوي على:

## Logo

في الجهة المناسبة للـRTL، استخدم:

**شعار موقعي الحالي واسمي الحالي فقط.**

لا تستخدم شعار الموقع المرجعي.

الـlogo يجب أن يكون واضحًا ومتوازنًا مع حجم الـnavigation.

# 5. Desktop Navigation

في الـdesktop أريد Navigation واضحًا ومضغوطًا أفقيًا.

الفكرة العامة:

```text
[Logo]       الرئيسية
             الحلقات الجديدة
             الدراما الآسيوية ▼
             الأفلام الآسيوية
             برامج الترفيه
                                      🔍
```

اجعل العناصر موزعة بشكل متوازن.

### الرئيسية

تحتوي على icon للـHome.

### الحلقات الجديدة

رابط مباشر لصفحة أحدث الحلقات.

### الدراما الآسيوية

Dropdown menu.

يحتوي على:

* قائمة الدراما
* الدراما القادمة
* الدراما التي تبث حاليًا
* الدراما المنتهية مؤخرًا
* الدراما المعاد رفعها / المتجددة
* الدراما الكورية
* الدراما اليابانية
* الدراما الصينية والتايوانية
* الدراما التايلاندية
* الدراما الفلبينية

اجعل الـdropdown:

* RTL.
* مرتب.
* واضح.
* يظهر عند hover على desktop.
* قابل للاستخدام بالـclick أيضًا.
* لا يخرج خارج الشاشة.

---

# 6. Mobile Navigation

على الشاشات الصغيرة لا تحاول ضغط الـdesktop navigation.

أنشئ Mobile Navigation مستقل.

استخدم:

* Hamburger button.
* Slide-in side menu.
* RTL.
* Overlay خلف القائمة.
* زر إغلاق واضح.
* animation ناعم.

القائمة تحتوي على نفس التصنيفات السابقة.

يجب أن تكون تجربة الـmobile ممتازة وليس مجرد نسخة مصغرة من desktop.

---

# 7. Search

في الـHeader يوجد Search icon.

عند الضغط عليه:

افتح Search Overlay / Popup أنيق.

يحتوي على:

```text
البحث في [اسم موقعي]

[ ابدأ البحث...                         🔍 ]
```

المطلوب:

* animation ناعم.
* background overlay.
* إغلاق عند الضغط خارج الـpopup.
* إغلاق بزر X.
* دعم Enter للبحث.
* البحث في المسلسلات والأفلام الموجودة في الموقع.
* دعم RTL.
* نتائج البحث تكون مرتبة وواضحة.
* لا تستخدم رابط البحث الخاص بالموقع المرجعي.

إذا كان المشروع يحتوي أصلًا على Search functionality، اربط التصميم الجديد بها بدل بناء نظام بحث منفصل.

# 8. STICKY HEADER

اجعل الـHeader Sticky.

عند النزول في الصفحة:

* يبقى الـHeader ظاهرًا.
* لا يغطي المحتوى.
* استخدم shadow خفيف.
* animation بسيطة.
* لا تجعل الـHeader ضخمًا.

على mobile يجب أن يعمل الـsticky header أيضًا.

# 9. HERO / FEATURED CAROUSEL

أسفل الـHeader مباشرة أريد Hero Carousel كبير للأعمال المميزة.

الفكرة الأساسية:

```text
┌─────────────────────────────────────────────┐
│                                             │
│       Poster   Poster   Poster   Poster      │
│                                             │
│           ‹                    ›             │
│              •  •  •                        │
└─────────────────────────────────────────────┘
```

خصائصه:

* Horizontal carousel.
* RTL friendly.
* Posters كبيرة وواضحة.
* عنوان العمل يظهر بطريقة أنيقة.
* arrows يمين ويسار.
* pagination dots.
* autoplay.
* transition smooth.
* pause عند hover إن كان مناسبًا.
* touch/swipe على mobile.
* لا يحدث layout shift.
* lazy-load للصور.

في التصميم المرجعي كان carousel يعرض تقريبًا عناصر بعرض 336px وارتفاع منطقة يقارب 468px، لكن لا تستخدم هذه الأرقام بشكل جامد؛ اجعلها Responsive حسب حجم الشاشة.

### Desktop

اعرض عدة Posters في نفس الوقت.

### Tablet

اعرض عددًا أقل.

### Mobile

اعرض Poster أو Posterين بشكل مناسب بدون قص الصورة.

```text
الحلقات الآسيوية الجديدة
```

# 13. Poster Carousel Sections

بعد قسم الحلقات الجديدة، أنشئ عدة أقسام Full Width.

كل قسم عبارة عن:

```text
عنوان القسم                         شاهد الكل

[Poster] [Poster] [Poster] [Poster] [Poster] ...
   ↑
  title
```

كل Poster:

* Aspect ratio قريب من 376×525.
* Border radius بسيط.
* object-fit: cover.
* title تحت الصورة.
* overlay icon عند hover.
* transition ناعم.
* clickable بالكامل.
* lazy loading.

في التصميم المرجعي كان عرض عنصر الـcarousel حوالي 209px على desktop، لكن يجب أن يكون Responsive.

# 15. Section Header

كل Section يجب أن يكون له Header موحد.

مثل:

```text
الدراما الكورية                              شاهد الكل
────────────────────────────────────────────────────
```

أو التصميم البصري الأنسب حسب الـtheme.

اجعل:

* العنوان واضح.
* font weight مناسب.
* spacing ثابت.
* "شاهد الكل" واضح وقابل للنقر.

لا تجعل كل section يبدو منفصلًا عن الآخر بشكل عشوائي.

# 16. Movie / Drama Cards

كل card يجب أن يحتوي على:

```text
┌───────────────┐
│               │
│    POSTER     │
│               │
│       ▶       │
└───────────────┘
عنوان المسلسل
English Title
```

لكن لا تجعل النص طويلًا يكسر التصميم.

استخدم:

* line clamp.
* fixed/consistent card height.
* tooltip أو title attribute عند الحاجة.

# 17. Hover Effects

عند hover على Poster:

* zoom بسيط جدًا.
* overlay.
* يظهر play/arrow icon.
* transition سريع وناعم.

لا تبالغ في animations.

* عنوان الحلقة.

Desktop:

عدة أعمدة.

Tablet:

عدد أقل.

Mobile:


مع:

* Active state.
* hover state.
* disabled state.
* RTL.
* mobile friendly.

لا تستخدم شكل WordPress القديم حرفيًا.

# 20. Footer

Footer بسيط ونظيف.

* اسم موقعي الحالي.
* Copyright ديناميكي.

مثال:

```text

جميع الحقوق محفوظة © 2026
```

# 23. Performance

حافظ على الأداء.

استخدم:

* lazy loading للصور.
* responsive images إذا كان النظام يدعمها.
* CSS transitions بدل animations ثقيلة.
* لا تحمل مكتبات ضخمة بدون داعٍ.
* لا تضف Owl Carousel أو jQuery فقط لأن الموقع المرجعي يستخدمها.

إذا كان المشروع يستخدم React/Next/Vite أو framework حديث، استخدم مكتبة carousel حديثة أو implementation مناسب للـframework.

**لا تقلد تقنية الموقع القديم؛ قلد النتيجة والـUX فقط.**

# 32. Final Quality Check

بعد التنفيذ، لا تكتفِ بأن الصفحة "تشتغل".

راجع بصريًا:

* spacing
* alignment
* card sizes
* poster ratios
* typography
* header height
* dropdown positioning
* carousel arrows
* pagination dots
* mobile menu
* search overlay
* responsive breakpoints
* RTL
* footer spacing.

إذا ظهر أي شيء غير متناسق، أصلحه.

**الهدف النهائي:**

موقع عربي احترافي للمسلسلات والأفلام الآسيوية، مستوحى من الـstructure والـUX الموجودين في الـreference HTML الذي أعطيتك إياه، لكن مبني من الصفر وبـbranding ومحتوى وassets خاصة بموقعي.
